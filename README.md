**Grid-Linker** は、ブラウザひとつで動作する、インストール不要の思考整理・ノードマップ作成ツールです。
単一のHTMLファイルで完結しており、データはお使いのブラウザ内（IndexedDB）に保存されます。

---

## ✨ 特徴

*   **⚡ 完全ローカル動作**: サーバーへのデータ送信は一切ありません。プライバシー重視の設計です。
*   **💾 自動保存**: 操作ごとにブラウザのデータベース(IndexedDB)に自動保存されます。
*   **🎨 自由な表現**:
    *   5種類のリンク線（矢印、双方向、不確定、等価など）
    *   ノードのグループ化（枠作成）
    *   背景への画像・動画設定（ぼかし・透明度調整機能付き）
*   **🌙 ダークモード**: 目に優しいダークテーマを標準搭載。
*   **🚀 多機能**:
    *   メモ帳からのノード一括生成
    *   JSON形式でのバックアップ・復元
    *   URLによる図の共有機能（構造データのみ）
    *   無限キャンバス（ズーム/パン）

## 📖 使い方

1.  開きます。
2.  **ノード作成**: キャンバス上の何もないところを右クリックし、「ここにノードを作成」を選択（またはメモ欄から一括追加）。
3.  **リンク接続**: ノード右端の赤い丸（●）をドラッグして、他のノードに繋げます。
4.  **編集**: ノードをダブルクリックでテキスト編集。
5.  **設定**: 左サイドバーの「設定・背景・容量」からテーマや背景を変更できます。

### ショートカット / 操作
*   **ホイール**: 拡大・縮小
*   **ドラッグ**: キャンバス移動
*   **Ctrl + ドラッグ**: 範囲選択
*   **Ctrl + Click**: 複数選択
*   **Delete / Backspace**: 選択した要素の削除
*   **右クリック**: コンテキストメニュー（中継点の追加など）

## 🛠️ インストール（ローカルで使用する場合）

このツールは単一のHTMLファイルです。インターネットがない環境でも動作します。

1.  このリポジトリの `index.html` をダウンロードします。
2.  ファイルを直接 Chrome / Edge / Safari 等のブラウザにドラッグ＆ドロップしてください。

## ⚠️ データについて

*   データはブラウザの **IndexedDB** に保存されます。
*   ブラウザのキャッシュクリア（履歴の削除など）を行うとデータが消える可能性があります。
*   重要なデータは、サイドバーの「JSON保存」ボタンから定期的にバックアップを取ることを推奨します。
